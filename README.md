# YouTube Clickbait Analyser

CLI-приложение для анализа CSV-файлов со статистикой YouTube-канала. Определяет кликбейтные видео — те, у которых высокий CTR при низком удержании аудитории.

## Требования

- Python 3.11+
- [Poetry](https://python-poetry.org/)

## Установка

```bash
poetry install
```

## Использование

```bash
python main.py --files stats1.csv stats2.csv --report clickbait

```

### Пример вывода

```
Название                                   CTR (%)    Удержание (%)
---------------------------------------  ---------  ---------------
Секрет который скрывают тимлиды               25.0             22.0
Как я спал по 4 часа и ничего не понял        22.5             28.0
Как я задолжал ревьюеру 1000 строк кода       21.0             35.0
Купил джуну макбук и он уволился              19.0             38.0
Я бросил IT и стал фермером                   18.2             35.0
```

### Критерии кликбейта

Видео считается кликбейтным, если выполняются **оба** условия:

| Метрика          | Порог  |
|------------------|--------|
| `ctr`            | > 15 % |
| `retention_rate` | < 40 % |

Результаты отсортированы по убыванию CTR.

## Доступные отчёты

| Название    | Описание                                        |
|-------------|-------------------------------------------------|
| `clickbait` | Высокий CTR + низкое удержание                  |

Чтобы добавить новый отчёт — создайте наследника `BaseReport` и зарегистрируйте его в `reports/__init__.py`.
